Jens Rantil's personal website
==============================
Hosts a blog and a few static pages.

Generated using [Hugo](https://gohugo.io).

You can find all the content in Markdown files in the `content` directory.

To develop
----------
```bash
$ git clone https://github.com/luizdepra/hugo-coder.git themes/hugo-coder
$ hugo server serve
```
